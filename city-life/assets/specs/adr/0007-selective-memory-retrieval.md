# Retrieve memory selectively

A citizen starts with body-free guidance and relevant Task Bead references, not a complete Memory index or corpus. Discovery returns bounded summaries and excerpts with canonical identity, selected-state address, lifecycle, match provenance, and honest continuation or completeness; it never expands a complete body. Exact recall preserves the selected current or retained-state address, complete body, attribution, and every required structured field without truncation or substitution. Any always-present orientation is bounded and body-free. Rig scope guides discovery but never changes ownership, namespace authority, or the meaning of an explicitly addressed Memory.
