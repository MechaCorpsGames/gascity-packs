# Cite citizen memory with project-qualified references

A Task Bead may carry a project-qualified `related` reference to a Memory Bead and may separately pin an exact retained state with a Historical Bead Reference. City Life resolves the current Task independently from the citizen's Memory binding and refuses an ambiguous or unverifiable result. The edge is informational, non-blocking, and body-free; it grants no authority to recall the target body. An unpinned edge follows the target's current state, while a pin keeps its exact meaning for as long as that state is retained. Archive, restore, and resolution changes never silently retarget it; the shared Graph and federation contract governs endpoint validation and restricted outcomes.
