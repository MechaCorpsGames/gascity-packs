# Give each citizen one Memory project

Each citizen has one canonical Memory Beads project. Within its city, Gas City's binding-qualified source-agent name is the citizen identity; an opaque route locates the project and its Project ID verifies durable storage identity. Every instance of that citizen resolves the same project, and no BQN or project participates in more than one citizen binding within the city. Lifecycle changes never silently replace, delete, or share that project; a new BQN is a new citizen. City Life owns resolution, namespace enforcement, rig relevance, and retrieval policy; Beads owns Memory identity, retained states, attribution, concurrency, references, and archive and restore behavior.
