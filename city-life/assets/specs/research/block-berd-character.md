# Berd: lessons on designing AI with character

**Snapshot:** 2026-08-18. Twenty-five claims from Block's article and the shipped `block/berd` personas survived adversarial verification.

## Observed

- Berd ships a cast of named personas whose differences combine prompt, visual identity, role, skills, and tools.
- Persona is encoded in Markdown plus small metadata; no fine-tuning is required.
- The strongest personas use flaws as capability: pushback, selectivity, or unpredictability changes the work they are good at.
- The prompt doctrine suppresses decorative personality during consent, error, and warning moments.
- Memory is separate from persona. The agent proposes durable writes instead of saving silently, but Berd's memory is a shared user model rather than per-persona knowledge.

## Implications for City Life

- Citizen continuity requires source-agent prompt and skill continuity as well as Memory continuity. A healthy Memory project cannot compensate for a missing persona or loadout.
- Personality should affect useful judgment without obscuring errors, authorization boundaries, or health failures.
- Durable capture remains deliberate. Shared conversation may communicate knowledge, but it should not merge citizens' Memory projects.
- Persona depth can vary by role; conformance should prove delivery, not prescribe prompt length.
