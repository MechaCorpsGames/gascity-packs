# City Life

City Life is a planned Gas City pack for turning named agents into durable AI
colleagues: citizens with a stable persona, useful skills, searchable sessions,
and curated Memory Beads.

This directory contains the public design corpus for community discussion. Pack
implementation will follow the specifications gathered here.
